Planned cloud architecture

ESP32-S3 → Wi-Fi → MQTT Broker → Backend → Database → Web Dashboard

Planned backend: Python or Node.js. Planned database: SQL or SQLite. Firmware interfaces: Analog, PWM, I2C, SPI, and UART. The current sensor demo uses Analog, I2C, and SPI; PWM and UART remain firmware capabilities.
